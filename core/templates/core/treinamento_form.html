Participantes Internos (Colaboradores do Call Center)

Caso deseje adicionar colaboradores internos via lista, você pode utilizar o arquivo CSV padrão. Essa planilha permite carregar rapidamente matrículas, dispensando a seleção manual individual.

Clique aqui para baixar o modelo: baixar planilha padrão de matrículas

Instruções importantes:

  • O arquivo deve estar no formato CSV.
  • Deve conter exatamente uma coluna chamada matricula.
  • Inclua apenas uma matrícula por linha, sem cabeçalhos adicionais.
  • A planilha deve ser salva com codificação UTF-8.
  • Matrículas inválidas ou com caracteres não numéricos serão ignoradas.

Participantes Externos

Para treinamentos com participantes externos ao quadro funcional do call center, utilize a planilha padrão no formato .xlsx. Nela você deverá informar corretamente os dados dos participantes que constarão na lista de presença.

Você pode baixar o modelo aqui: baixar modelo base de participantes externos

Instruções importantes:

  • O arquivo deve estar no formato .xlsx (Excel).
  • As seguintes colunas são obrigatórias: Nome, E-mail, Cargo, Unidade, Cidade, Estado, Gestor, Data de Participação.
  • A planilha deve conter apenas um cabeçalho e os dados iniciando na linha 2.
  • Certifique-se de que o e-mail está no formato válido e que a data esteja no padrão reconhecível pelo Excel.
  • Registros incompletos serão ignorados e exibidos como erro.
